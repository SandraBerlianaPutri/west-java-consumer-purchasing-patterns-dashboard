# Exploring Consumer Purchasing Patterns in West Java

## About
This project explores consumer purchasing patterns in West Java Province in 2023 through exploratory data analysis and interactive data visualization. The dashboard presents purchasing-related information in an accessible format to support the exploration of consumer behavior and potential business insights.

## Project Dashboard
- [Explore the Interactive Dashboard on Looker Studio](https://lookerstudio.google.com/u/0/reporting/f6569705-088f-4aee-854e-924bc73a1aad/page/p_2u4pxyhkhd)

## Dataset
- **Geographic coverage:** West Java Province, Indonesia
- **Period:** 2023
- **Subject:** Community purchasing patterns.

## Methods
- **Exploratory Data Analysis (EDA):** Examined the available data to identify purchasing patterns and notable trends.
- **Data Visualization:** Presented key information through charts and dashboard components.
- **Interactive Dashboard Development:** Organized the analysis in Looker Studio to make the results easier to explore.
